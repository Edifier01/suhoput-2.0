## Воспроизводимая локальная база

Точные digests Linux-образов зафиксированы в [Compose](../infra/compose.yaml). WordPress, CLI, база и почта находятся в закрытой сети; отдельный обратный прокси публикует только loopback-порты. На этой машине прямое опубликование портов закрытой сети не работало; прокси сохраняет запрет исходящей сети приложения. Локальные DB/admin-пароли создаются init-local.ps1 и не печатаются.

WooCommerce 11.2.0 SHA-256: `66E91B45B057B64C73D4521111CEA5BDC78C4C89DE8FA2CA4B18B9422706D722`. Его readme содержит устаревший Stable tag 11.1.2; фактическая активная версия из WC_VERSION — 11.2.0. Пользоваться фактической версией, а не полем readme. [Требования WordPress](https://wordpress.org/about/requirements/), [требования WooCommerce](https://woocommerce.com/document/server-requirements/).

HPOS включён, синхронизация в posts отключена. Собственные плагины объявляют поддержку и используют CRUD для заказа. На основе создавался и удалялся синтетический заказ; расширенные сценарии ещё требуют отдельных задач. [Руководство HPOS](https://developer.woocommerce.com/docs/features/orders/high-performance-order-storage/recipe-book/).
